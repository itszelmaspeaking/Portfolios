静态网站，无需安装依赖。首页为 index.html，图片与附件位于 assets，案例与 PRD 位于 docs。

## GitHub Pages 发布

1. 在 itszelmaspeaking 账号下创建 Public 仓库，建议名称为 itszelmaspeaking.github.io。
2. 解压本文件包，将包内所有文件和 assets、docs 两个文件夹上传到仓库根目录。不要直接上传 ZIP，也不要再套一层文件夹。
3. 确保仓库根目录可见 index.html，并提交到 main 分支。
4. 进入仓库 Settings → Pages，在 Source 选择 Deploy from a branch。
5. 选择 main 分支与 / (root)，保存。
6. 等待部署完成，以 Settings → Pages 显示的网站地址为准。

若使用仓库名 itszelmaspeaking.github.io，预期地址为 https://itszelmaspeaking.github.io/，这不是已部署成功的声明。
